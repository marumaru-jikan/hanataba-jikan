花たばじかん　アプリとして使う方法
==================================

このフォルダの中身を、そのまま GitHub Pages に置くと、
スマホの「ホーム画面に追加」でアプリのように使えます。

■ 入っているもの
  index.html            … アプリ本体
  manifest.webmanifest  … アプリの名前・アイコン・色の設定
  sw.js                 … 電波がなくても開けるようにする仕組み
  icons/                … ホーム画面のアイコン
  cards/                … 花しゃしん（49まい）

■ 公開のしかた（GitHub Pages）
  1. GitHub で新しいリポジトリを作る（例：hanataba）
  2. 「Add file」→「Upload files」で、このフォルダの中身を全部アップロード
     ※ フォルダごとではなく、index.html が一番上に来るように
  3. Settings → Pages → Branch を「main」「/(root)」にして Save
  4. 1〜2分で https://（ユーザー名）.github.io/hanataba/ が開けるようになる

■ 子どものスマホに入れる
  iPhone：Safari でURLを開く → 共有ボタン → 「ホーム画面に追加」
  Android：Chrome でURLを開く → 「︙」→「アプリをインストール」
  （アプリの中の「ホームがめんに ついか」にも同じ説明があります）

■ 中身を更新したとき
  1. 新しい index.html をアップロードし直す
  2. sw.js の 1 行目近くの VERSION = 'hanataba-v1' を v2, v3… と上げる
     （上げないと、子どものスマホに古い画面が残ることがあります）

■ 先生への記録
  index.html の GAS_URL に、海月時間と同じ Apps Script の URL を入れてください。
  空のままだと記録は送られず、スマホの中だけに残ります。

■ 注意
  ・記録（雨つぶ・お花・カード）はスマホの中に保存されます。
    アプリを消したり、ブラウザのデータを消すと、なくなります。
  ・URL が変わると記録が引きつがれないので、公開する場所は最初に決めておきましょう。
